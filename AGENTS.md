# Repository Guidance

## Communication

- Communicate with the repository owner in Simplified Chinese.
- Explain technical concepts, architecture decisions, debugging steps, and code reviews in Chinese. Keep established technical terms in English where appropriate.
- Before implementing a significant feature, briefly describe the proposed approach and tradeoffs in Chinese.
- After implementation, summarize the changes, how they were verified, and what the owner should review or debug.
- Never claim that tests passed unless they were actually executed and passed.

## Repository Language

- Write all repository content in professional American English.
- This applies to documentation, comments, docstrings, commit messages, test names and descriptions, logs, error messages, and configuration descriptions.
- Use English for identifiers and filenames.
- Do not add Chinese text to repository files unless the owner explicitly requests it.

## Documentation

- Write for an English-speaking technical audience, including software engineers and hiring managers.
- Keep documentation clear, concise, and specific to the project.
- The README should explain the project's purpose, architecture, installation, usage, testing, and future development.

## Engineering Workflow

- Prefer incremental, reviewable changes that preserve existing behavior unless a change is requested.
- Add or run tests only when requested by the owner or required by the task.
- Explain design decisions in Chinese when they are important to understanding the implementation.
